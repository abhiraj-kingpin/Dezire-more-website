Bulk Import

Add many products at once with a spreadsheet + all your photos

Step 1 — Get the template

Download the template, fill in one row per product using Excel or Google Sheets, then save/export as CSV.

Columns: name, category, subcategory, price, originalPrice, fabric, sku, colors, sizes, occasion, description, tags, inStock, stockCount, images, video
category must be one of: sarees, blouses, jewelry, accessories, dress-materials, ready-to-wear, western
colors / sizes / occasion / tags — separate multiple values with a semicolon, e.g. Red;Gold
images — the exact photo filenames for that product, separated by a semicolon, e.g. saree1.jpg;saree2.jpg (must match the files you select in Step 3 exactly)
video — optional, one filename for a showcase clip of the outfit, e.g. saree1-video.mp4 (also selected in Step 3)
